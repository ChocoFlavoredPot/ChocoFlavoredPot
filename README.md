## 한종윤 (Han Jong Yoon)

광운대학교 소프트웨어학부 3학년입니다. 리눅스 시스템 프로그래밍과 임베디드 소프트웨어를 공부하고 있습니다.

### 프로젝트

| 프로젝트 | 내용 | 사용 기술 |
|---|---|---|
| [ftp-server](https://github.com/ChocoFlavoredPot/ftp-server) | 소켓, fork, 시그널로 구현한 FTP 서버·클라이언트 (시스템프로그래밍 과제, 9단계) | C, Linux |
| [집중관리허브](https://github.com/smkim991/--project) | 집중을 방해하는 프로그램과 웹사이트를 차단하는 데스크톱 앱 (4인 팀 프로젝트, 주제 제안 및 차단 기능 구현) | C#, WinForms |

### 기술

- 언어 : C, C#, Python, ARM AArch64 어셈블리
- 환경 : Ubuntu, gcc, Makefile, Git
- 보드 : Raspberry Pi 3, Jetson Nano
